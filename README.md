# Kuya Predictor

App for letting users predict results of each match in the Fifa World Cup 2026.
Custom made for friends in Brutal Bros Son and Co.
Made in React hosted on Vercel and uses database hosted on Supabase.

## Features

Users can predict details of each match including final score, first goals, etc., with an option to double one match per group.

![scores example](/public/examples/score.png)

After the match is over and the match's details are put into the database, scores are awarded and other users's predictions can be compared.

![results example](/public/examples/results.png)

In additon, users can predict the standings of each group durring the group stage and the final bracket tournament durring the knockout stage.

![groups example](/public/examples/groups.png)
![knockout example](/public/examples/knockout.png)

One of the aims of the app is to create competition between friends. A scores page can show all users and how well they are doing compared to each other.

![scores example](/public/examples/scores.png)
